# Delivery preference

The user has explicitly requested that completed changes in this repository be committed and pushed automatically. After finishing and verifying the requested work, commit all files belonging to that task and push to `origin/main` without asking for another confirmation.

Preserve concurrent and unrelated work. Fetch and integrate newer remote changes when necessary; resolve conflicts without discarding other developers' changes. Use a normal push, never a force push. Report the resulting commit and, for website changes, verify the deployed URL when possible. If the environment requires an approval for Git or network access, use its normal approval mechanism.
